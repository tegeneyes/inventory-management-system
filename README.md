# Inventory Management System

A React-based inventory management application for tracking products, stock levels, inventory movements, and business performance through a clean dashboard interface.

## Overview

This project is designed to help manage product records and monitor key inventory operations efficiently. It includes UI components for inventory tracking, orders, customer data, and sales analytics.

## Features

- Product inventory management
- Stock level tracking
- Order management
- Customer overview
- Revenue and growth analytics
- Responsive dashboard interface

## Tech Stack

- React + Vite
- JavaScript
- HTML
- CSS
- Material UI
- React Router
- React Data Grid
- ApexCharts
- Material Icons
